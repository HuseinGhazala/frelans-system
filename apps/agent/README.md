# راصد — برنامج الديسكتوب

برنامج Electron بيتسطب على جهاز الموظف (Windows دلوقتي، وmacOS بعدين).

## بيعمل إيه

- تسجيل الدخول بنفس حساب الموقع، وشاشة موافقة على المراقبة أول مرة.
- تسجيل حضور / استراحة / انصراف (من الشباك أو من أيقونة شريط المهام).
- **فقط أثناء الحضور:** بيعد ضغطات الكيبورد وحركات الماوس (أعداد بس، من غير أي حرف)،
  وبيسجل البرنامج النشط واسم الموقع لكل دقيقة.
- **الخمول:** بعد حد الخمول (افتراضي 5 دقايق) من غير نشاط، الوقت بيقف وما بيتحسبش.
  قفل الشاشة أو نوم الجهاز = خمول فورًا. بعد 30 دقيقة خمول بيسجل انصراف تلقائي عند بداية الخمول.
- **أوفلاين:** لو النت فصل، كل حاجة بتتحفظ على الجهاز (`queue.json`) وبتتبعت أول ما يرجع.
- الوقت بيتحسب بساعة السيرفر، فتغيير ساعة الجهاز ما بيأثرش.
- قفل الشباك بيخفيه بس؛ البرنامج بيفضل في شريط المهام وبيفتح تلقائي مع Windows.
- "خروج" من شريط المهام بيسجل انصراف الأول.

## الشات (من 0.2.0)

تبويب **"الشات"** جنب **"الحضور"** في الشباك — نفس شات الموقع:

- المحادثات الخاصة والجروبات والقناة العامة، مع بحث في المحادثات والرسايل.
- محادثة جديدة / جروب جديد، وإدارة الجروب (تغيير الاسم، إضافة وشيل أعضاء، الخروج).
- رد على رسالة، منشن بـ `@` (قايمة بالأعضاء)، تعديل وحذف رسايلك (السيرفر بيحدد المدة المسموحة).
- علامة القراءة (✓ اتبعتت، ✓✓ اتقرت — وفي الجروب عدد اللي قروها)، "بيكتب..."، ونقطة حالة لكل شخص
  (بيشتغل / خامل / في استراحة / متصل / غير متصل).
- صور وملفات (زرار 📎، أو لصق صورة، أو سحب وإفلات) ورسايل صوتية (🎤) — تتبعت وتتعرض وتشتغل جوه البرنامج،
  والملفات تتحفظ على الجهاز بزرار "حفظ".
- **إشعار Windows** لما توصل رسالة والشباك مش قدامك (القناة العامة: بس لو حد عملك منشن).
  الضغط على الإشعار بيفتح المحادثة.
- عدد الرسايل الجديدة: نقطة حمرا على أيقونة شريط المهام (جنب الساعة) وعلى أيقونة البرنامج في الـ taskbar،
  والعدد في الـ tooltip وفي قايمة الأيقونة.

إزاي شغال:

- التوكن بيفضل في الـ main process. الواجهة بتطلب كل حاجة عن طريق الـ preload (`window.rased.chat`)،
  والـ main بيكلم `/api/agent/v1/chat/*` بالتوكن.
- الأحداث اللحظية: اتصال SSE واحد (`/api/agent/v1/chat/stream`) من الـ main بـ `fetch` (من غير مكتبات)،
  بيعيد الاتصال تلقائي بـ backoff أُسّي (1 ثانية → دقيقة)، وبيقطع ويعيد لو مفيش ولا ping وصل في 70 ثانية،
  وفورًا بعد ما الجهاز يصحى من النوم. بعد كل اتصال بيجيب القايمة من الأول عشان أي حاجة فاتت.
- المرفقات: الـ main بيجيب الملف بالتوكن ويبعت البايتات للواجهة، والواجهة بتعرضها كـ `blob:` URL —
  الـ CSP اتزود عليه `blob:` للصور والصوت بس.
- الميكروفون: مسموح لشباك البرنامج بس، وصوت بس (مفيش كاميرا). أي صلاحية تانية مرفوضة.
- الشباك بقى بيكبر، ولو عرضه 720px أو أكتر القايمة والمحادثة بيظهروا جنب بعض.
- **للنشر:** nginx لازم يكون فيه `proxy_buffering off` لمسار `/api/agent/v1/chat/stream` (زي `/api/chat/stream`).

## التطوير

```bash
pnpm install
RASED_SERVER_URL=http://localhost:3000 pnpm dev   # يبني ويشغّل
pnpm test                                          # اختبارات المنطق (core/)
```

## ملف التسطيب لـ Windows

من GitHub: **Actions → Build Windows agent → Run workflow**، وبعد ما يخلص حمّل
`Rased-Setup-x.y.z.exe` من **Artifacts**. رابط الموقع الافتراضي بييجي من متغير المستودع
`RASED_SERVER_URL`، والموظف يقدر يغيّره من "إعدادات السيرفر" في شاشة الدخول.

> من غير شهادة توقيع (Code Signing)، Windows هيظهر تحذير SmartScreen أول مرة:
> "More info" ← "Run anyway".

### إصدار نسخة جديدة

1. غيّر `version` في `package.json`.
2. اعمل tag باسم `agent-v<النسخة>` على الـ commit وادفعه: `git tag -a agent-v0.4.0 -m "..." && git push origin agent-v0.4.0`.
3. الـ workflow بيبني ويرفع على GitHub Releases: `Rased-Setup.exe` (الرابط الثابت لصفحة التحميل)، و`Rased-Setup-x.y.z.exe`، و`latest.yml` و`.blockmap` (للتحديث التلقائي).

## التحديث التلقائي (من 0.3.0)

- البرنامج المتسطب بيسأل `https://github.com/HuseinGhazala/frelans-system/releases/latest/download/latest.yml` بعد دقيقة من الفتح، وكل 4 ساعات، ولما الجهاز يصحى من النوم.
- لو فيه نسخة أحدث بينزّلها في الخلفية، ويطلّع إشعار "تحديث جديد لراصد"، ويظهر في قايمة الأيقونة "تحديث البرنامج لنسخة x (إعادة تشغيل)".
- بيتسطب:
  - لوحده من غير ما يسأل، لو الموظف مش مسجل حضور والشباك مقفول؛
  - أو لما الموظف يدوس على الإشعار أو "تحديث البرنامج" (بيسجل انصراف الأول زي الخروج العادي، وبعدين بيفتح تاني)؛
  - أو لما البرنامج يتقفل (مع قفل الجهاز مثلًا).
- النسخ قبل 0.3.0 مافيهاش التحديث ده، فالموظف لازم يسطّب 0.3.0 بإيده مرة واحدة.
- وقت التطوير (`pnpm dev`) التحديث مقفول.

## الهيكل

```
src/core/      المنطق (من غير Electron) + الاختبارات: الحالة، الخمول، تجميع الدقائق، الطابور،
               وللشات: قارئ SSE، الـ backoff، حالة المحادثات/غير المقروء، النص والمنشن
src/main/      Electron: الشباك، شريط المهام، الكيبورد/الماوس، النافذة النشطة، التخزين، الشات (chat.ts)
src/preload/   الجسر الآمن بين الواجهة والبرنامج
src/renderer/  الواجهة (React) — app.tsx (الحضور + التبويبات) و chat.tsx (الشات)
```
