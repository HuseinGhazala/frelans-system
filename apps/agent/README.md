# راصد — برنامج الديسكتوب

برنامج Electron بيتسطب على جهاز الموظف (Windows دلوقتي، وmacOS بعدين).

## بيعمل إيه

- تسجيل الدخول بنفس حساب الموقع، وشاشة موافقة على المراقبة أول مرة.
- تسجيل حضور / استراحة / انصراف (من الشباك أو من أيقونة شريط المهام).
- **فقط أثناء الحضور:** بيعد ضغطات الكيبورد وحركات الماوس (أعداد بس، من غير أي حرف)،
  وبيسجل البرنامج النشط واسم الموقع لكل دقيقة.
- **الخمول:** بعد حد الخمول (افتراضي 5 دقايق) من غير نشاط، الوقت بيقف وما بيتحسبش.
  قفل الشاشة أو نوم الجهاز = خمول فورًا. بعد 30 دقيقة خمول بيسجل انصراف تلقائي عند بداية الخمول.
- **أوفلاين:** لو النت فصل، كل حاجة بتتحفظ على الجهاز (`queue.json`) وبتتبعت أول ما يرجع.
- الوقت بيتحسب بساعة السيرفر، فتغيير ساعة الجهاز ما بيأثرش.
- قفل الشباك بيخفيه بس؛ البرنامج بيفضل في شريط المهام وبيفتح تلقائي مع Windows.
- "خروج" من شريط المهام بيسجل انصراف الأول.

## التطوير

```bash
pnpm install
RASED_SERVER_URL=http://localhost:3000 pnpm dev   # يبني ويشغّل
pnpm test                                          # اختبارات المنطق (core/)
```

## ملف التسطيب لـ Windows

من GitHub: **Actions → Build Windows agent → Run workflow**، وبعد ما يخلص حمّل
`Rased-Setup-x.y.z.exe` من **Artifacts**. رابط الموقع الافتراضي بييجي من متغير المستودع
`RASED_SERVER_URL`، والموظف يقدر يغيّره من "إعدادات السيرفر" في شاشة الدخول.

> من غير شهادة توقيع (Code Signing)، Windows هيظهر تحذير SmartScreen أول مرة:
> "More info" ← "Run anyway".

## الهيكل

```
src/core/      المنطق (من غير Electron) + الاختبارات: الحالة، الخمول، تجميع الدقائق، الطابور
src/main/      Electron: الشباك، شريط المهام، الكيبورد/الماوس، النافذة النشطة، التخزين
src/preload/   الجسر الآمن بين الواجهة والبرنامج
src/renderer/  الواجهة (React)
```
