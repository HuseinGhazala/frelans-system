# راصد — نظام متابعة الموظفين عن بُعد

نظام داخلي لمتابعة حضور وساعات ونشاط الموظفين اللي بيشتغلوا من البيت.
المواصفات الكاملة في [`docs/SPEC.md`](docs/SPEC.md).

## هيكل المشروع

```
apps/web     لوحة التحكم (Next.js + PostgreSQL/Prisma) — للأدمن والموظفين
apps/agent   برنامج الديسكتوب (Electron) — Windows
deploy/      ملفات النشر على سيرفر (Docker Compose + Caddy)
docs/        المواصفات وبروبتات التصميم ودليل النشر
```

## التشغيل محليًا

المتطلبات: Node.js 22، pnpm 10، PostgreSQL 16 (أو Docker).

```bash
docker compose up -d                 # قاعدة البيانات
cp apps/web/.env.example apps/web/.env
# عدّل DATABASE_URL لـ postgresql://rased:rased@localhost:5432/rased
pnpm install
pnpm --filter web db:migrate         # إنشاء الجداول
pnpm dev                             # http://localhost:3000
```

أول مرة تفتح الموقع هيطلب منك تعمل حساب المدير. بعدها ضيف الموظفين من صفحة **الموظفين**،
وكل موظف هيوصله رابط دعوة يعيّن منه كلمة المرور (لو الإيميل مش متظبط، الرابط بيظهر لك تنسخه وتبعته).

## الأوامر

| الأمر | الوظيفة |
|------|---------|
| `pnpm dev` | تشغيل وضع التطوير |
| `pnpm build` | بناء نسخة الإنتاج |
| `pnpm test` | الاختبارات |
| `pnpm typecheck` | فحص الأنواع |
| `pnpm lint` | فحص الكود |

## نظام العمل لكل موظف

- **بالساعات:** عدد ساعات يومي ثابت لكل موظف، حضور وانصراف ومراقبة من البرنامج، والخصم والإضافي بالساعة (الحساب شهري صافي).
- **بالتاسكات:** من غير حضور ولا مراقبة. التاسكات من Trello، والتسليم = نقل الكارت لليست التسليم. مرتب ثابت، والأدمن بيشوف التسليمات المتأخرة ويحدد الخصم بنفسه.
